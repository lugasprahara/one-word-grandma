You explained ChatGPT to Grandma exactly once, over the phone. She never saw the name written down — she only heard it. Hours later she texts the family chat about the AI, and the word that arrives is **geepeetee**: the whole future of technology, spelled precisely the way it sounded to her. This program writes that one word, and nothing else, to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
